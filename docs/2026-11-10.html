How DeepL keeps closest-exit routing during maintenance with AWS Cloud WAN

DeepL uses AWS Cloud WAN with AS_PATH prepend routing to take a single AWS Direct Connect link offline for maintenance while other regions maintain their "closest-exit" egress behavior. By prepending autonomous system numbers to BGP paths advertised on the link being maintained, traffic from that region's core network edge is rerouted to alternate locations while unaffected regions continue using their local exits. This approach avoids the need for more-specific per-link prefixes and keeps routes stable during the maintenance window.
