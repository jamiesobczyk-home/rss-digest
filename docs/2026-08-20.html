New Study Challenges Common Assumptions About Screen Time For Kids

A Finnish study found that children who accumulated more screen time showed better cognitive processing in adolescence, though the type of screen activity matters—digital activities involving learning, problem-solving, and creativity are associated with cognitive benefits. Physical activity's relationship to cognition was more nuanced, with light-intensity activity benefiting girls' working memory and guided activity benefiting boys', while surprisingly, lower levels of unsupervised physical activity correlated with better cognitive processing. Researchers conclude that screen time should not be viewed as inherently harmful but rather balanced with activities—both digital and physical—that promote active thinking.

Hacker News · 8:29 PM

Turns are Better than Radians (2022)

Casey Muratori argues that code should use normalized angles on a [0, 1] scale ("turns") instead of radians. Most code multiplies by π to convert to radians before calling trig functions, only for those functions to immediately divide by π internally—a wasteful round trip that could be eliminated entirely. The [0, 1] range is computationally faster, simpler to understand, and more precise in binary floating-point, since common angles like 0.25 (90°) and 0.5 (180°) are exactly representable, whereas their radian equivalents never are.
