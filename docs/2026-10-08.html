Cisco NX-OS Software Python Sandbox Escape Vulnerability

A vulnerability in Cisco NX-OS Software's Python interpreter allows authenticated local attackers with low privileges to escape the Python sandbox and execute arbitrary commands on the underlying operating system by manipulating specific functions.
