AWS Architecture Blog · 1:00 PM

Data governance with annotations in Amazon S3

S3 Annotations let you attach up to 1,000 structured governance records directly to S3 objects—such as classification, retention policy, PII inventory, and jurisdiction—without rewriting the object or changing its storage location. These annotations travel with the object during copies and replication, remain updatable in place, and stay readable even when archived, while remaining queryable at scale through S3 Metadata tables. Key design requirements include: sequencing annotations before Object Lock retention, opting into annotation preservation for multipart uploads, using version-scoped deletes in governed buckets, separating IAM permissions for writing, reading, and deleting annotations, and treating generated labels as proposals requiring validation before triggering irreversible actions.

AWS Architecture Blog · 12:35 PM

Recommended resilience testing in the next generation of AWS Resilience Hub

AWS Resilience Hub's recommended resilience testing provides four pre-configured fault injection tests—Availability Zone recovery, dependency validation, Multi-Region isolation, and Multi-Region recovery—that automatically validate how services respond to failures without manual experiment design. The tests use AWS Fault Injection Service to inject faults and evaluate results against resilience policies and recovery time objectives, generating automated pass/fail outcomes with reports. Dependency validation, the most requested capability, helps identify which dependencies applications can tolerate losing by blocking connectivity and monitoring service health through configurable alarms.
