Claude helps solve math's biggest open problem

Anthropic mathematician Levent Alpöge used Claude to prove the Riemann hypothesis—a 167-year-old math problem about prime numbers that carries a $1M prize—in roughly six weeks, with computer verification confirming the proof's correctness despite its 17 million lines making it impossible for humans to fully understand. The breakthrough demonstrates AI's ability to solve problems mathematicians expected to take decades longer, though critics from the Association for Human Mathematics dismissed it as "little more than publicity" for AI labs. A competing proof by Alessandro Masullo surfaced hours later but contained errors.

A Partial Evaluator for C

Tempo is a partial evaluator for C programs that automates specialization by identifying which inputs are known versus unknown at specialization time. Using binding-time, alias, and side-effect analyses, it tracks value flow through code and generates a specialized version that eliminates computations based on static values. The tool supports both compile-time and runtime specialization and has been applied across operating systems, networking, graphics, scientific computation, and other domains.
