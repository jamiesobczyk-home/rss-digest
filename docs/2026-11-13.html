Cisco BroadWorks Out-of-Band Blind XML External Entity Injection Vulnerability

A vulnerability in Cisco BroadWorks' XML Parser allows unauthenticated remote attackers to read sensitive configuration files by exploiting improper external entity resolution in the Open Client Interface (OCI). An attacker can send a crafted XML message to the OCI-P service to view sensitive files with Cisco BroadWorks user privileges. Cisco has released software updates to address this High-severity issue (CVE-2026-20320) with no available workarounds.

Inside an enterprise AI agent: A governed, observable loop architecture

Enterprise AI agents differ from chatbots by operating in continuous loops through five phases—Understand, Plan, Retrieve, Reason, Act and Observe—to solve multi-step problems while maintaining governance and observability at each layer. The reference architecture organizes this around five tiers: an API gateway with identity controls, the agent runtime, knowledge and state systems, platform services (models and tools), and a trust and control framework that gates risky actions through guardrails, evaluations, confidence scoring, and human approval. This layered design, implemented via AWS managed services, embeds security, cost controls, and audit trails from the ground up rather than retrofitting them afterward.

FAA Expands AI Advice to Manage Air Traffic Congestion Across Entire US Airspace

The FAA is expanding its $875 million AI-powered SMART system to all 22 U.S. air traffic control centers, building on initial deployment over Washington, DC, which rerouted 180 flights and saved an average of 10 minutes and 80 gallons of fuel per flight. The system analyzes weather, flight paths, traffic flow, and staffing to generate routing recommendations that human FAA specialists validate before controllers receive them, and local controllers retain final authority to accept or reject the suggestions. SMART cannot replace air traffic controllers or take control of aircraft.
