Google's DeepCrossAttention achieves comparable model quality up to 3x faster

Google Research's DeepCrossAttention (DCA) enhances transformer networks by using learnable weights and depth-wise cross-attention to dynamically combine outputs from previous layers, replacing the rigid, equal-weight summation of traditional residual connections. This architectural improvement allows models to achieve comparable quality up to three times faster while reducing parameters by 30-40% with negligible overall increase. DCA reframes residual learning as a dynamic routing problem, enabling each layer to selectively route and combine features from preceding layers based on input context rather than applying uniform weighting.

Tabernetes: A Kubernetes cluster whose nodes are browser tabs

Tabernetes is a Kubernetes cluster that uses browser tabs as compute nodes, allowing participants to contribute resources by opening a tab that runs a Linux kernel in WebAssembly. When a tab closes, Kubernetes automatically relocates its pods to other available tabs in the cluster. The system integrates with standard Kubernetes using a custom container runtime called tabc, enabling ordinary containerized workloads to run across distributed browser tabs.
