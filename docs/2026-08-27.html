AWS Architecture Blog · 12:33 PM

Closing the AI agent trust gap with graduated autonomy

Graduated autonomy is an architectural pattern that closes the "trust gap" in AI agents by dynamically granting or revoking permissions based on sustained performance rather than using binary access controls. The framework uses a scoring engine to measure agent reliability across safety, accuracy, consistency, compliance, and efficiency dimensions, then maps scores to four tiers (Probation, Supervised, Trusted, Autonomous) with corresponding permission levels. The solution combines pre-execution filters, infrastructure-level policy enforcement, post-execution auditing, and delivery gates to ensure agents operate safely while maintaining operational value.

Microsoft Azure Blog · 11:00 AM

The Economics of Agent Optimization: Four ways to lower the cost

Microsoft Foundry enables cost optimization for AI agents through four runtime levers: routing requests to the appropriate model based on complexity, caching prompts to avoid reprocessing repeated content, optimizing prompt and agent instructions to reduce token volume, and using observability to measure savings and guide continuous improvement. Rather than using a single frontier model for all requests, production systems should match model choice, deployment type, and caching strategy to task requirements while measuring both cost-per-request and cost-per-completed-outcome. These levers form a continuous improvement cycle where traces inform optimization, proven tasks become fine-tuning candidates, and results feed back into routing decisions.
