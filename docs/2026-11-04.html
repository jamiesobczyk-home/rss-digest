Cisco Secure Email Gateway SQL Injection Vulnerability

A critical SQL injection vulnerability in Cisco AsyncOS Software for Cisco Secure Email Gateway allows unauthenticated attackers to execute arbitrary commands with root privileges by sending crafted emails containing malicious SQL statements through insufficient email parsing validation. Cisco has released software updates to address the flaw, with no workarounds available. The vulnerability is tracked as CVE-2026-76461.

Slashdot · 4:00 AM

Dinosaur Blood Found In Fossils For the First Time

Researchers discovered intact red blood cells and biomolecules inside 115-million-year-old fossilized bones of a juvenile Brazilian theropod dinosaur (Aratasaurus museunacionali), challenging assumptions about how long biological material can survive. A manganese oxide called hausmannite preserved the cellular structures, including heme and collagen amino acids, likely through rapid burial in a low-oxygen but microbe-rich environment. The findings could advance understanding of dinosaur metabolism and blood evolution, and inform how ancient life might be preserved in extreme environments.
