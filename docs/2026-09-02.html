Hybrid cloud orchestration: Modernizing on-premises infrastructure management with AWS

AWS presents a hybrid cloud orchestration solution using serverless technologies to centrally manage distributed on-premises infrastructure at scale, addressing challenges like operational inconsistency, manual bottlenecks, and fragmented visibility across geographically dispersed data centers. The architecture combines an event-driven engine built on Lambda, Step Functions, and DynamoDB with Amazon EKS Anywhere clusters and vendor-agnostic Redfish APIs for bare-metal hardware management, enabling automated lifecycle operations for thousands of servers and Kubernetes clusters. Unified observability through AWS Distro for OpenTelemetry and Grafana, coupled with integrated DNS, certificate, and secure access management, allow seamless coordination between cloud-based orchestration and on-premises execution.

AWS Architecture Blog · 8:09 AM

MCP went stateless: Is your AWS MCP server deployment well-architected?

MCP's July 28, 2026 revision eliminated session-based protocol requirements, removing the need for sticky routing, session stores, and handshake infrastructure that previously locked clients to specific server instances. The stateless design aligns with AWS Well-Architected Framework best practices, reduces costs by deleting unnecessary infrastructure, and makes AWS Lambda a natural deployment target. Teams managing their own MCP stacks should migrate to the 2026-07-28 specification while maintaining backward-compatible support for pre-2026 clients until traffic on the legacy version reaches zero.
