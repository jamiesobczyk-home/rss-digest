Cisco Secure Firewall Adaptive Security Appliance and Secure Firewall Threat Defense Software SSL VPN Denial of Service Vulnerability

A vulnerability in Cisco Secure Firewall ASA and FTD Software allows unauthenticated remote attackers to cause denial of service by sending numerous new SSL/TLS connections that deplete system memory and buffers, slowing or stopping SSL VPN processing. The flaw stems from improper memory management and affects all ASA and FTD platforms; manual device reloads may be required to restore operations. Cisco has released software updates with no workarounds available (CVE-2024-20260, High severity).

Better Vector Search for Long Documents: Chunking Inside Manticore Search

Manticore Search now supports automatic document chunking for vector search through a new `chunk_strategy` parameter, eliminating the problem of long documents exceeding model token limits and losing searchability. The feature offers five strategies (truncate, mean, fixed, recursive, sentence) configured directly in table definitions, requiring no additional pipelines or separate chunk tables. When tested on the Manticore manual, chunking improved recall from 55.1% to 83.3% for content buried past the model's input window, though at increased cost of 2.5× RAM and 4× ingest time.
