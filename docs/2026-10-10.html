Food processing influences metabolism and brain activity

Virginia Tech researchers found that meals identical in calories, macronutrients, and weight but differing in processing levels produced distinct metabolic and brain responses in healthy adults—ultraprocessed meals triggered higher insulin release, greater energy expenditure, and different activity in the brain's reward system. The findings suggest that food processing itself influences the body's metabolic response independently of nutritional content, potentially explaining why ultraprocessed foods are associated with overconsumption and adverse health outcomes. The study, published in Nature Metabolism, compared 32 participants' fMRI and metabolic responses to minimally and highly processed meals.

Telegram Desktop vulnerability allowed any user's file to be stolen

Telegram Desktop through version 7.2.8 contained a critical vulnerability (CVE-2026-107181) allowing attackers to steal files and take over accounts by clicking a crafted link. The flaw combined command injection through unescaped separators in IPC communication between Telegram processes with an unsecured internal URI scheme that reads files without permission verification. REA Reverse – Engineer Anything

REA is a reverse-engineering tool that helps coding agents understand how software works by inspecting running programs, decompiling code, and explaining functionality. Users can ask their agent to analyze software behavior—such as why Windows Calculator returns 220 for "200 + 10%" or how Chrome's dinosaur game increases in speed—and the agent provides the underlying logic and can rebuild features with modifications. The tool automates the manual process of decoding assembly instructions and tracing function calls to recover the rules driving a program's behavior.

Hacker News · 6:28 PM

Compiling Rust to readable C with Eurydice

Eurydice is a compiler that converts Rust code to readable C, developed by researchers at Inria and Microsoft as part of the Aeneas formal verification project. It's particularly useful for high-assurance software where existing verification tools expect C code, providing a bridge for projects transitioning from Rust or environments lacking a Rust compiler. Unlike typical compilers, Eurydice preserves code structure and evaluation order through the conversion, though it faces challenges with Rust-specific features like iterators and generics that don't map directly to C.
