Beyond the Ceiling: How Customer Challenges Are Redefining EVPN for the Campus

Traditional EVPN campus networks hit a scalability wall when every access leaf must maintain routes for all endpoints, causing memory overflow on smaller switches and expanding security risks across large Layer 2 domains. Cisco and Meta developed EVPN Subnet Slicing to shift route state to aggregation tiers instead of access leaves, reducing memory pressure and security exposure without requiring network re-addressing. This L3-Optimized IRB approach lets campuses scale efficiently while supporting modern AI-driven workloads and meeting security demands within existing budgets.

Cisco Expressway Series Remote Code Execution Vulnerability

A critical remote code execution vulnerability in Cisco Expressway Series devices allows unauthenticated attackers to execute arbitrary commands as root by exploiting persistent cookies and insufficient TLS certificate validation in the database service. Jevons Paradox in AI: Cheaper Tokens Won't Pay for Capex

AI token volume is surging (up 330x at Google since 2024) but token prices are falling at nearly the same rate, leaving revenue roughly flat despite massive infrastructure spending by hyperscalers ($560 billion in capex in 2026's first three quarters). The Jevons Paradox doesn't apply here because price elasticity near 1 means buyers maintain fixed budgets even as token prices plummet—a tenfold price cut buys tenfold more tokens for the same $2 million, not more spending. Vendors are increasingly turning to outcome-based pricing to close the gap between rising capex costs and stagnant inference revenue.
