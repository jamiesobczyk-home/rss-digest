Cisco Informational for Emergency Distrust of eMudhra Root and Intermediate Certificate Authorities

A critical security compromise of eMudhra-managed Certificate Authorities was discovered between October 17-20, 2026, with private keys for eight intermediate certificates compromised due to an error in the Key Generation Ceremony from April 2025. These private keys can be brute-forced within seconds, allowing unauthorized acquisition of the credentials. Cisco has issued an advisory about affected products, with the rating classified as informational.

Cisco Security Advisory · 12:29 PM

Cisco UCS and UCS-Based Appliances UEFI Shell Secure Boot Bypass Vulnerability

A Cisco UEFI Shell vulnerability in UCS Servers and UCS-based appliances allows authenticated users or unauthenticated attackers with physical access to bypass Secure Boot by using shell commands to modify UEFI memory variables and execute unauthorized software. Cisco has released software updates to address the issue, with no workarounds available. The vulnerability has a High security rating and is tracked as CVE-2026-20293.

Physicists Send an Unblockable Message Using Gravity

University of Queensland researchers transmitted a message through a brick wall using gravity by moving an elevator's counterweight between positions representing binary digits, with a gravimeter detecting the gravitational field changes. Unlike electromagnetic signals, gravitational signals cannot be blocked by ordinary physical barriers, though the current system transmits only 1 bit per minute. Future gravity-based communication could achieve speeds of up to 15 bits per minute over ranges of 500 meters using quantum sensors.
