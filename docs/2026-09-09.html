Cisco Security Advisory · 11:00 AM

Cisco UCS and UCS-Based Appliances UEFI Shell Secure Boot Bypass Vulnerability

A vulnerability in Cisco UCS Servers and UCS-based appliances allows authenticated users or unauthenticated attackers with physical access to bypass UEFI Secure Boot by using memory write commands available in the UEFI Shell. An attacker could exploit this to manipulate the preboot environment and execute unauthorized software on affected devices. Cisco has released software updates to address the issue; no workarounds are available.

Hacker News · 5:01 AM

Lotus Notes and the dangers of starting from scratch

Lotus Notes, launched in 1989, pioneered advanced features like encryption, rich text formatting, and read receipts years before competing email systems, fundamentally reshaping how organizations communicated. The software evolved from PLATO Notes, a collaborative forum system created in 1973 at the University of Illinois by David Woolley, which enabled early forms of threaded discussions and asynchronous communication across networked terminals. Ray Ozzie, who had used PLATO as a student, developed Lotus Notes to recreate that collaborative work environment in the commercial sector, creating an all-in-one platform for notes, email, and application development rather than just another email client.
