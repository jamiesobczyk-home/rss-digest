Publishing LMS courses with a Kiro SCORM pipeline

Kiro is an agentic AI tool that automates conversion of training material (slides, docs, playbooks) into SCORM 1.2 packages for learning management systems through a six-step pipeline: source intake, planning, authoring lessons, linting, building, and validation. The pipeline uses Steering files for persistent knowledge, Specs for formalizing development, and Hooks for automated checks, allowing authors to focus on content while Kiro handles packaging mechanics. The result is an upload-ready .zip file that delivers to an LMS without manual restructuring or manifest editing.

Vessel-specific voyage optimization with machine learning: Manta on AWS

Manta Marine Technologies delivers vessel-specific voyage optimization using machine learning models trained on each ship's operational history rather than industry averages, built on AWS infrastructure that processes up to 3 billion data points per training run across EC2, ECS, RDS, and other services. The cloud-native solution uses Apache Airflow to orchestrate data pipelines and continuously retrains models as new voyage data arrives, enabling the system to deliver increasingly tailored guidance for fuel efficiency and profitability. Manta expects fuel savings of 2–4 percent per vessel and achieved 25–30 percent better price performance by using AWS Graviton-based instances.

AWS Architecture Blog · 12:10 PM

How Anchorage Digital and Turnkey verify code with AWS Nitro Enclaves

Anchorage Digital and Turnkey built VisualSign, an open-source transaction parser running on AWS Nitro Enclaves that protects cryptocurrency wallets from phishing by making complex transactions human-readable with cryptographic proof of correctness. The system uses attestation documents and reproducible builds to verify that the exact audited code processed the transaction, eliminating blind signing risks. The underlying architecture—reproducible builds, enclave-hosted computation, and attestation-gated access—applies broadly to any high-trust workflow requiring verifiable compute beyond blockchain.
