Cisco Identity Services Engine Authorization Bypass Vulnerabilities

Multiple vulnerabilities in Cisco Identity Services Engine (ISE) and ISE Passive Identity Connector lack server-side validation of Administrator permissions, allowing authenticated remote attackers to modify device configurations by submitting crafted HTTP requests. The vulnerabilities require valid Administrator credentials to exploit and specifically allow modification of file descriptions on certain pages. Cisco has released software updates to address these issues, with no available workarounds.

Using voltage glitching to unleash the A100 in my mining card

A researcher discovered a voltage fault injection vulnerability in NVIDIA's GA100 GPU die that allows arbitrary fuses to be blown, enabling conversion of a CMP 170HX mining card into a functional A100-80GB with ~1.2x faster performance due to more enabled compute cores. The exploited vulnerability works because NVIDIA uses fuses for product segmentation and security—but in this case, blown fuses grant additional access rather than restrict it, contrary to proper security design. Features like NVLink, PCIe Gen4, and others disabled in the mining variant can be unlocked through this approach.
