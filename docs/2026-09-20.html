Microsoft agentically ports Copilot runtime to Rust for $120K

Microsoft used AI agents to port the Copilot runtime from TypeScript to Rust, converting 430,000 lines of code into 800,000 lines across a 14.5-week effort that cost $120,000 in AI token usage plus three weeks of developer time. The Rust version delivered dramatic performance gains—15.9x faster on one benchmark and memory consumption dropping from 1,383 MB to 126 MB—though the AI agents introduced several dozen regressions that required manual fixes, highlighting remaining challenges in AI's Rust capabilities.

Spain Orders Blocks on Archive.today and Its Mirrors

Spain's Intellectual Property Commission has ordered Spanish ISPs to block Archive.today and its mirror domains (Archive.is, Archive.ph, Archive.li) following a complaint from an unnamed rights holder, redirecting users to a government page labeling the site "illegal." The administrative decision, which required no court ruling, was executed under a 2021 protocol between the Ministry of Culture, rights holders, and ISPs to block mirror sites within 24 hours of notice. Archive.today is a web archiving service used by researchers and journalists to preserve snapshots of web pages that have been removed, altered, or placed behind paywalls.

Hacker News · 12:15 AM

UTF-8000: Unlimited UTF-8

UTF-8000 extends UTF-8 to support arbitrarily large code units by clarifying how to split the highest bits of the first byte into self-synchronization and start bits, then stripe these bits across continuation bytes as needed. It maintains backward compatibility with ASCII and standard UTF-8 while preserving the self-synchronization property that allows any byte in a file to be instantly identified as either a first byte or continuation byte.
