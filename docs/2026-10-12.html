This AI factory builds tiny machines from code

Atomic Machines, founded by ex-Uber self-driving chief Jeff Holden, emerged from stealth with $250 million to operate an AI-guided factory that converts digital code designs into tiny, physical machines without requiring retooling. The company's Matter Compiler technology focuses on microscopic devices like pumps and motors that traditional chip factories cannot produce, with its first product being PrimeSwitch, a fingertip-sized power switch for AI servers. The startup aims to democratize physical hardware manufacturing, making it as accessible as writing software code.

Hacker News · 1:36 AM

Postgres isn't slow, your storage is

A POSETTE 2026 talk examines how storage performance is often the root cause of PostgreSQL issues at scale, including slow ingestion, inconsistent read latency, lagging autovacuum, and replication lag that accumulate as working sets exceed available memory. These problems occur because client queries and background maintenance operations (heap writes, WAL synchronization, checkpoints, VACUUM) compete for the same storage bandwidth and I/O capacity, with slower storage amplifying contention. The speaker ran a benchmark comparing PostgreSQL on EBS versus local NVMe to show that local NVMe reduces I/O cost by orders of magnitude—from milliseconds to microseconds—sharply improving system performance.

Type-safe HTML templating in Zig

A developer built zt, a type-safe HTML templating library for Zig inspired by Go's Templ, that transpiles templates to Zig code at compile time for full type checking and performance.
