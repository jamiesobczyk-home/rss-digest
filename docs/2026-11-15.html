Disk encryption on NetBSD – achieving secrecy

NetBSD disk encryption faces a fundamental challenge: the operating system must load unencrypted files during boot, making complete encryption difficult without specialized hardware or a small unencrypted boot partition. The key decision involves identifying which directories contain sensitive data (like /home, /var, and /etc) versus which must remain readable for the system to function, with approaches ranging from encrypting just user directories to more complex encrypted root filesystem solutions using ramdisks.
