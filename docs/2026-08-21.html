DeepSeek-v4-flash-vision-exp

DeepSeek-v4-flash-vision-exp is a multimodal model that processes images alongside text to describe pictures, read screenshots, and analyze charts in JPEG, PNG, GIF, and WebP formats. Users can provide images through three methods: base64-encoded inline data, external URLs (up to 8192 characters, 32 MiB max), or via the Files API for larger files up to 64 MiB. The model supports a detail parameter to control image processing, with "low" downscaling to 512×512 for speed and "high" preserving the original image.
