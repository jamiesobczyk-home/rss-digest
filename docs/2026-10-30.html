How BMW Group accelerated connected vehicle workloads on AWS Graviton

BMW Group migrated its Connected Vehicle platform from x86 to AWS Graviton processors using Karpenter for dynamic provisioning, dual-architecture CI/CD builds, and phased opt-in rollout with Kubernetes taints and node selectors. The migration achieved approximately $600,000 in annual infrastructure savings, 40% price-performance improvement, and 57% CPU reduction for key services, with over 65% of the platform now running on Graviton across production environments. Success relied on supporting both architectures simultaneously, validating on platform services first, and letting application teams migrate independently without service disruption.

Azure Cloud HSM Hardware Audit Logging: Verifiable audit trails for security and compliance

Microsoft Azure announced Hardware Audit Logging for Azure Cloud HSM, which captures audit records directly from the hardware for management operations including user authentication, policy changes, and key lifecycle activities. The feature delivers human-readable logs and HSM-signed binary audit data to Azure Monitor Log Analytics, enabling independent cryptographic verification of record authenticity. The immutable logging is designed for regulated industries to demonstrate controlled administration of sensitive cryptographic systems and support compliance investigations.
