Cisco Blogs · 9:23 AM

Segment Routing Fundamentals: Decoding SRv6 and Network Programming [Part 2]

SRv6 uses specially formatted IPv6 addresses as Segment Identifiers (SIDs) that encode network instructions, enabling the network to function like a programmable entity with naming conventions borrowed from object-oriented programming. An SRv6 SID consists of an administrator-configured Locator (SR block and Node ID), followed by automatically generated Function and Argument fields that specify what instruction the router should execute on traffic. The SRv6 router publishes the Locator through the IGP and creates routing table entries for each SID, combining both transport to the endpoint and processing instruction specification in one mechanism.

How close can pure functional programming get to C?

A researcher optimized roc-deflate, a DEFLATE compression library written in the functional programming language Roc, and benchmarked it against libdeflate, a highly-tuned C implementation. On an M1 MacBook Pro, roc-deflate ran only 2.6% slower on average, while on an AMD Ryzen CPU it was 8.9% slower, demonstrating that functional programming can approach C-level performance despite the latter's architecture-specific optimizations. This result is notable given that Roc is still pre-release and its package ecosystem has undergone minimal optimization work.
