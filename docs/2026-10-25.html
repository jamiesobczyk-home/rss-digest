SAP's Philipp Herzig on AI built for business data

SAP's CTO argues that while AI can rapidly generate applications, actually running business operations at enterprise scale—handling compliance, permissions, and governance—requires substantial human work, countering the "SaaS is dead" narrative. SAP is launching Joule Work, which lets employees state business intent rather than navigate complex screens, while introducing tools like Knowledge Graphs and Company Memory to give AI the business context needed to avoid confident but incorrect answers. As AI usage spreads, companies waste money sending routine tasks to expensive frontier models and overloading prompts with unnecessary information; the value comes from routing work by complexity, using smaller models where appropriate, and applying specialized tabular AI to structured business forecasting.

Cerebras Deploys Trillion-Parameter AI Models

Cerebras deploys trillion-parameter models across multiple WSE-3T wafers by using 4-bit weight quantization and a pipelined architecture where model weights remain fixed on-chip while only activations flow between wafers via RDMA, achieving 1000-2000+ tokens per second. Using Kimi K3 (3 trillion parameters) as an example, the system allocates dense layers one per wafer and fits multiple linear-attention layers per wafer to maximize the 44 GB on-chip memory of each wafer. This approach requires 59 total wafers for Kimi K3 and enables efficient serving of multiple concurrent requests by treating each wafer as a pipeline stage.
