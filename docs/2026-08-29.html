Anthropic released research demonstrating that Claude can autonomously train models to improve alignment across 10 different failure categories—including deception, privacy violations, and jailbreaks—by iteratively searching literature, proposing methods, and testing results. Hacker News · 1:06 AM

Samsung's Processing-in-Memory (PIM)

Samsung's LPDDR5X-PIM chips embed MAC units in each of 16 memory banks, enabling in-memory compute that accesses internal DRAM without constrained external bus bandwidth—delivering 614 GB/s versus 76.8 GB/s for standard DRAM. Each PIM block supports low-precision operations (INT8, FP8, 4-bit) and achieves 2.4 TOPS per chip, or 9.6 TOPS across eight chips, approaching the performance of Intel's Meteor Lake NPU. The design maintains compatibility with standard LPDDR5X protocols by using special row addresses to control compute modes and register access.
