The scourge of x86 emulation

FEX-Emu explores the fundamental challenge of emulating x86 processors on ARM hardware: x86 uses Total Store Ordering (TSO), a strict memory model where stores are immediately visible to all processors, while ARM uses a relaxed memory model that prioritizes efficiency by allowing delayed visibility of memory changes. This architectural mismatch creates multi-faceted technical problems that must be solved to make x86 emulation on ARM systems work correctly.
